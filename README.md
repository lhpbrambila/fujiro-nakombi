FUJIRO NAKOMBI
Um jogo de estratégia feudal japonesa em modo escuro, desenvolvido como uma aplicação web autossuficiente em arquivo único (index.html).

Visão Geral
FUJIRO NAKOMBI coloca o jogador no comando de uma facção em um cenário de estratégia feudal sombria. O projeto foi estruturado para rodar diretamente no navegador sem necessidade de build complexo ou dependências externas de servidor, unindo progressão estratégica, pesquisa doutrinária, eventos dinâmicos e persistência portátil de dados.

Principais Recursos
Ambientação Feudal em Modo Escuro: Interface visual sóbria e de alto contraste pensada para leitura prolongada e atmosfera imersiva.

Iconografia Própria em SVG: Ícones vetoriais inline desenhados sob medida, dispensando emojis do sistema operacional.

Três Árvores de Pesquisa de Doutrina: Caminhos distintos de evolução estratégica para moldar o estilo de jogo e os bônus da facção.

Eventos Dinâmicos de Era: Ocorrências que alteram o cenário e exigem decisões estratégicas conforme o tempo avança.

Exportação e Importação de Save em Base64: Backup e transferência rápidos do estado da partida por meio de códigos Base64.

Arquitetura em Arquivo Único (index.html): Todo o código estrutural, visual e lógico concentrado em um único arquivo HTML, ideal para hospedagem estática no GitHub Pages.

Como Jogar / Executar
Faça o download ou clone este repositório.

Abra o arquivo index.html diretamente em qualquer navegador moderno (desktop ou mobile), ou acesse a versão publicada via GitHub Pages.

Gerencie sua facção, avance pelas árvores de doutrina, reaja aos eventos de cada era e utilize a função de Exportar / Importar Save (Base64) sempre que quiser salvar ou migrar seu progresso.

Refinamento de balanceamento entre as três árvores de doutrina.

Ajustes contínuos de usabilidade e responsividade em telas menores
